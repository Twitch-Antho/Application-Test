Un mini-jeu d'arcade inspiré des jeux de survie en salle, créé en HTML, CSS et JavaScript. Le but est simple : éviter les météores, progresser dans les niveaux et battre son meilleur score.

## Aperçu

- Contrôle précis et fluide
- Augmentation progressive de la difficulté
- Gameplay rapide et addictif
- Compatible clavier et tactile
- Interface visuelle style néon / arcade

## Comment jouer

1. Ouvrir `index.html` dans un navigateur.
2. Déplacer le vaisseau avec les flèches gauche/droite ou les touches `A` / `D`.
3. Sur mobile, glisser le doigt dans l'arène pour esquiver les impacts.
4. Éviter les météores, accumuler des points et essayer de repousser vos limites.

## Règles du jeu

- Chaque météore évité rapporte des points.
- Le niveau augmente avec le temps.
- La vitesse du jeu augmente progressivement.
- La partie se termine dès qu'un météore touche le vaisseau.

## Contrôles

| Plateforme | Action |
| --- | --- |
| Ordinateur | Flèches gauche / droite ou `A` / `D` |
| Mobile | Glisser le doigt dans l'arène |
