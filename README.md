# Neon Dodge

Un mini-jeu d'arcade créé en HTML, CSS et JavaScript.

## Jouer

Ouvrir `index.html` dans un navigateur, puis utiliser les flèches gauche/droite (ou `A`/`D`) pour déplacer le vaisseau. Sur mobile, glisser le doigt dans l'arène.

Le but est d'éviter les météores et de battre son meilleur score. Le niveau et la vitesse augmentent progressivement.
